# Source Log Template

Copy this structure per source into the running source log (e.g. `sources.md`). Group
entries under headings per sub-topic/use-case established in Phase 0 of SKILL.md.

```
### <Short title of the source>

- Link: <URL>
- Download status: <Downloaded as `papers/filename.pdf` (size, verified genuine PDF)>
  OR <Read online only, not downloaded — reason if applicable>
  OR <Considered, rejected — one-line reason>
- Author(s) / publisher: <names, affiliation, venue/year if known>
- Credibility tier: <1/2/3, per source-credibility-rubric.md>
- Contents: <2-4 sentences, in your own words, on what this source actually contains.
  Not a copy of the abstract — paraphrase. If you must quote, keep it under ~30 words
  and mark it as a quote.>
- Takeaway: <1-3 sentences: what you personally learned from it and how it answers or
  informs the research question. This is the part a reader actually wants.>
```

## Rules for filling this in

- Fill this in **as you go**, not after finishing all research. Memory of "which paper
  said what" degrades fast across a multi-source task.
- "Download status" must reflect what actually happened, verified by checking the file
  (see `download-verification-checklist.md`), not what you expect to have happened.
- If a source was checked and found irrelevant or redundant with another already-logged
  source, still note it briefly under a "considered but not used in depth" section at the
  end — this shows the search was thorough, not cherry-picked.
- If any images, datasets, or other assets were downloaded, log them with their license
  and required attribution explicitly, in their own subsection.
- End the log with a short, honest section on any access restrictions or gaps
  encountered (blocked downloads, paywalled sources, sources you couldn't verify) — do
  not bury this or omit it.
